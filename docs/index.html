Results

The primary metric for this task is precision@50, because the operational question is not “is the page generally declining?” but “which 50 pages deserve an editorial review first?” On that metric, the random forest model performed best on the client-grouped holdout, with a strong lift over the transparent baseline.

Ranked recommendations

  1. Review the highest-ranked stale and visible pages first.
  2. Use reason codes to explain why a page was selected for review.
  3. Move low-volume stale pages to a monitoring queue unless there is independent editorial evidence of opportunity.
  4. Re-run the queue after each content update cycle using the same validation and label logic.
  5. Use the ranked queue as a triage aid, not as an automatic publishing decision.
